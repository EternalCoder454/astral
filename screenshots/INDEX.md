# Screenshots

Regenerate with `scripts/screenshots.sh`. They are captured against a seeded
throwaway database, so nothing here is real chat content, and they are
committed so the README has something to show.

| File | What it shows |
|---|---|
| `01-chat.png` | A roleplay scene. Narration is set in a grey italic, speech is left full strength and weighted, so a long scene can be skimmed for what was said out loud. |
| `02-portrait.png` | The same scene with the character portrait panel open. |
| `03-welcome.png` | The home screen: the cast, and the worlds under them. |
| `04-new-chat.png` | The four ways to start: design a character, play a scene, plain chat, or import a card. |
| `05-characters.png` | The cast. |
| `06-character-editor.png` | Every card field, the world a character belongs to, and both images. |
| `07-worlds.png` | Every setting, with how much lore each holds and how much is waiting for review. |
| `08-world.png` | One world: who lives in it, one click from a scene, with its lorebook underneath. |
| `09-lorebook.png` | A lorebook: what triggers each entry, how confident the model was, and the review queue for anything it was unsure of. |
| `10-writing-styles.png` | Writing style presets. |
| `11-settings.png` | Model, sampling and how long Ollama keeps the model loaded. |

`REVIEW-PROMPT.md` beside these is a self-contained brief for having the
interface critiqued: hand it to a reviewer along with the eleven images.

All captured at 1240x820 in the dark scheme. A light scheme exists and inverts
the bubble relationship, since near white there is no headroom to lift a
surface above the page.
